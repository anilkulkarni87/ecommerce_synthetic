Engineered for decoupled POS, global scale, and governance

Deterministic by seed, executed in Polars, and structured around real-world retail boundaries.

Decoupled Retail POS

instore_accounts

POS registers capture phone_number, email, or both with customer_id = NULL, alongside active POS-only shoppers, anonymous walk-ins, and payment_token card fingerprints.

Omnichannel BOPIS & BORIS

fulfillment_type

Models ~18% Buy Online, Pick Up In Store (pickup_store_id, free pickup, no carrier shipment) and ~35% Buy Online, Return In Store (return_channel, return_store_id).

Cross-Channel Entity Resolution

--identity-noise

Injects duplicate profiles, temporal PII drift, and 5% household sharing across customers and instore_accounts, emitting cross-channel identity_ground_truth.parquet.

Clickstream & Guest Checkout

anonymous_id

100% of orders_online.session_id values link to purchase funnels, ~15% are guest checkouts (guest_email), and persistent anonymous_id cookies model pre-login browsing.

Global Multi-Region Localization

--regions global

Country packs (US, GB, DE, FR, CA, JP, AU, BR) localize customers, physical stores.country, currencies, FX rates, and VAT vs. sales-tax calculation.

GDPR / CCPA Consent & PII Tags

--compliance

Emits customer_consents.parquet plus 2% DSAR erasure tombstones and compiles 31 DIRECT_PII, INDIRECT_PII, and FINANCIAL column tags into Snowflake & Databricks DDL.

Direct-to-Database Streaming

--stream-to

Stream Polars chunks directly into DuckDB, Snowflake (write_pandas), Databricks UC Volumes, or BigQuery (LoadJob) with zero local Parquet files.

50M+ Chunked Parquet Persistence

--chunk-size

Streaming ChunkedParquetWriter flushes table/part-00000.parquet partitions every N rows (default 500K) to keep memory bounded on Large and XL runs.

Schema Topology & Data Dictionary (26 Tables)

24 core omnichannel tables (including ad_campaigns & ad_spend_daily) plus 2 optional governance/ER tables (customer_consents, identity_ground_truth).

Layers:

Multi-Warehouse Exporters & Direct Streaming

Load staged Parquet chunks via export or stream directly from memory via --stream-to with PK/FK constraints, PII tags, and analytical views.

Databricks Unity Catalog

Stages single or chunked Parquet directories to UC Volumes (or streams in-memory Parquet buffers), executes read_files() Delta CTAS, and applies UC column governance tags.

# Direct stream or export
$ ecommerce-synth generate --tier large --stream-to databricks --catalog dev --schema ecom
-- Governance tags applied automatically
ALTER TABLE dev.ecom.customers ALTER COLUMN email SET TAGS ('pii_classification' = 'DIRECT_PII', 'sensitivity' = 'HIGH');

Snowflake

Supports internal stage PUT + COPY INTO and zero-file write_pandas streaming, with auto-discovered connections.toml profiles and 4h MFA caching.

# Direct stream without local Parquet
$ ecommerce-synth generate --tier large --stream-to snowflake --database ECOM_DB --schema PROD
-- Governance tags applied automatically
ALTER TABLE ECOM_DB.PROD.customers MODIFY COLUMN email SET TAG pii_classification = 'DIRECT_PII', sensitivity = 'HIGH';

Google Cloud BigQuery

Streams DataFrames directly via load_table_from_dataframe or stages chunked Parquet files to GCS with native LoadJob ingestion.

# Direct stream to BigQuery
$ ecommerce-synth generate --tier medium --stream-to bigquery --project my-gcp-project --dataset ecom
-- Analytical view deployed
CREATE OR REPLACE VIEW `my-gcp-project.ecom.v_customer_360` AS ...

DuckDB

Zero-copy Polars registration via --stream-to duckdb or multi-part read_parquet([...]) export with custom --schema support.

# Stream directly into a custom schema
$ ecommerce-synth generate --tier medium --stream-to duckdb --database ./live.duckdb --schema retail
-- Query immediately
SELECT * FROM retail.v_customer_360 ORDER BY lifetime_spend DESC LIMIT 10;

SQL Recipes & Benchmark Queries

Ready-to-run analytical queries for cross-channel identity resolution, decoupled POS stitching, GDPR auditing, funnel attribution, and multi-currency GMV.

SELECT
  gt.record_type,
  gt.noise_type,
  COUNT(*) AS total_records,
  COUNT(DISTINCT gt.true_entity_id) AS canonical_entities
FROM identity_ground_truth gt
GROUP BY gt.record_type, gt.noise_type
ORDER BY total_records DESC;
SELECT
  ia.instore_account_id,
  c.customer_id AS matched_digital_id,
  COUNT(oi.transaction_id) AS pos_txns,
  ROUND(SUM(oi.total_amount_usd), 2) AS pos_spend_usd
FROM instore_accounts ia
LEFT JOIN customers c
  ON (ia.email IS NOT NULL AND LOWER(TRIM(ia.email)) = LOWER(TRIM(c.email)))
  OR (ia.phone_number IS NOT NULL AND RIGHT(REGEXP_REPLACE(ia.phone_number, '[^0-9]', '', 'g'), 10) = RIGHT(REGEXP_REPLACE(c.phone, '[^0-9]', '', 'g'), 10))
LEFT JOIN orders_instore oi ON ia.instore_account_id = oi.instore_account_id
GROUP BY 1, 2
ORDER BY pos_spend_usd DESC NULLS LAST;
SELECT
  cc.jurisdiction,
  cc.purpose,
  cc.status,
  COUNT(*) AS customer_count
FROM customer_consents cc
JOIN customers c ON cc.customer_id = c.customer_id
GROUP BY 1, 2, 3
ORDER BY 1, 2, 4 DESC;
SELECT
  o.device_type,
  o.fulfillment_type,
  COUNT(DISTINCT o.order_id) AS linked_orders,
  COUNT(DISTINCT cs.anonymous_id) AS stitched_cookies
FROM orders_online o
JOIN clickstream cs ON o.session_id = cs.session_id
GROUP BY 1, 2;
SELECT
  currency_code,
  tax_regime,
  COUNT(*) AS order_count,
  ROUND(SUM(total_amount), 2) AS local_gmv,
  ROUND(SUM(total_amount_usd), 2) AS usd_consolidated_gmv
FROM orders_online
GROUP BY 1, 2
ORDER BY usd_consolidated_gmv DESC;
