Engineered for global scale, streaming, and governance

Every generator is deterministic by seed, backed by Polars columnar execution, and aligned with warehouse governance requirements.

Global Multi-Region Localization

--regions global

Configurable country packs in config/regions.yaml (US, GB, DE, FR, CA, JP, AU, BR) with localized Faker names and addresses, ISO country codes, currencies, FX rates, and VAT vs. sales-tax rules.

GDPR / CCPA Consent & PII Tags

--compliance

Emits customer_consents.parquet across marketing, analytics, and personalization purposes plus 2% DSAR erasure tombstones. Compiles 31 DIRECT_PII, INDIRECT_PII, and FINANCIAL column tags into Snowflake & Databricks DDL.

Direct-to-Database Streaming

--stream-to

Stream generated DataFrame chunks straight into DuckDB, Snowflake (write_pandas), Databricks UC Volumes (in-memory buffers), or BigQuery (LoadJob) without saving local Parquet files.

50M+ Chunked Parquet Persistence

--chunk-size

Streaming ChunkedParquetWriter flushes table/part-00000.parquet partitions every N rows (default 500K) to keep memory bounded during Large (50M) and XL (500M) runs.

Entity Resolution Messy-Data Mode

--identity-noise

Injects realistic duplicate customer records (email aliases, phone reformatting, nicknames, typos, household splits) and outputs identity_ground_truth.parquet to benchmark Precision/Recall/F1.

True Clickstream-to-Order Attribution

session_id

100% of orders_online.session_id values link to complete clickstream purchase funnels ending at order_date, alongside loyalty_transactions.source_order_id linkage.

Multi-Warehouse Exporters & Direct Streaming

Load staged Parquet chunks via export or stream directly from memory via --stream-to, complete with PK/FK constraints, PII governance tags, and analytical views.

Databricks Unity Catalog

Stages single or chunked Parquet directories to UC Volumes (or streams in-memory Parquet buffers), executes read_files() Delta CTAS, and applies UC column governance tags.

# Direct stream or export
$ ecommerce-synth generate --tier large --stream-to databricks --catalog dev --schema ecom
-- Governance tags applied automatically
ALTER TABLE dev.ecom.customers ALTER COLUMN email SET TAGS ('pii_classification' = 'DIRECT_PII', 'sensitivity' = 'HIGH');

Snowflake

Supports both internal stage PUT + COPY INTO and zero-file write_pandas streaming, with auto-discovered connections.toml profiles, 4h MFA token caching, and MODIFY COLUMN ... SET TAG.

# Direct stream without local Parquet
$ ecommerce-synth generate --tier large --stream-to snowflake --database ECOM_DB --schema PROD
-- Governance tags applied automatically
ALTER TABLE ECOM_DB.PROD.customers MODIFY COLUMN email SET TAG pii_classification = 'DIRECT_PII', sensitivity = 'HIGH';

Google Cloud BigQuery

Streams DataFrames directly via load_table_from_dataframe or stages chunked Parquet files to GCS with native LoadJob ingestion and un-enforced PK/FK constraints.

# Direct stream to BigQuery
$ ecommerce-synth generate --tier medium --stream-to bigquery --project my-gcp-project --dataset ecom
-- Analytical view deployed
CREATE OR REPLACE VIEW `my-gcp-project.ecom.v_customer_360` AS ...

DuckDB

Zero-copy Polars registration via --stream-to duckdb or multi-part read_parquet([...]) export with custom --schema support.

# Stream directly into a custom schema
$ ecommerce-synth generate --tier medium --stream-to duckdb --database ./live.duckdb --schema retail
-- Query immediately
SELECT channel, COUNT(*) AS txns, SUM(total_amount) AS gmv FROM retail.v_omnichannel_sales GROUP BY 1;

SQL Recipes & Benchmark Queries

Ready-to-run analytical queries for entity resolution evaluation, GDPR consent auditing, funnel attribution, and multi-currency consolidation.

SELECT
  gt.noise_type,
  COUNT(*) AS duplicate_profiles,
  COUNT(DISTINCT gt.true_entity_id) AS canonical_entities
FROM identity_ground_truth gt
JOIN customers c ON gt.customer_id = c.customer_id
WHERE gt.is_duplicate = TRUE
GROUP BY gt.noise_type
ORDER BY duplicate_profiles DESC;
SELECT
  cc.jurisdiction,
  cc.purpose,
  cc.status,
  COUNT(*) AS customer_count
FROM customer_consents cc
JOIN customers c ON cc.customer_id = c.customer_id
GROUP BY 1, 2, 3
ORDER BY 1, 2, 4 DESC;
SELECT
  o.device_type,
  COUNT(DISTINCT o.order_id) AS linked_orders,
  ROUND(AVG(cs.session_events), 1) AS avg_events_before_purchase
FROM orders_online o
JOIN (
  SELECT session_id, COUNT(*) AS session_events
  FROM clickstream
  GROUP BY session_id
) cs ON o.session_id = cs.session_id
GROUP BY o.device_type;
SELECT
  currency_code,
  tax_regime,
  COUNT(*) AS order_count,
  ROUND(SUM(total_amount), 2) AS local_gmv,
  ROUND(SUM(total_amount_usd), 2) AS usd_consolidated_gmv
FROM orders_online
GROUP BY 1, 2
ORDER BY usd_consolidated_gmv DESC;
